# Prepare Raspberry Pi

## Purpose

Prepare the Raspberry Pi host so it starts from a clean, predictable baseline before control-deck software is installed.

## Preparation checklist

- verify network connectivity
- verify the Raspberry Pi hardware is working correctly
- verify the target monitor and cabling are working correctly
- remove unnecessary software and runtimes not required for this project
- reduce background services and bloat where practical
- configure the Raspberry Pi for this project's intended kiosk use
- once the software baseline is considered clean and ready, create a backup image

## Notes

- this checklist is operational guidance, not a product requirement
- changes should be documented so the host can be rebuilt consistently later
